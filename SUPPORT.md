# Suporte

## Você é responsável, aluno ou professor

As issues do GitHub não são o canal de atendimento. Fale com a **sua escola**: ela administra o Klass, cuida dos cadastros e é a responsável pelos dados de alunos e famílias.

Pedidos sobre dados pessoais (acesso, correção, exclusão) também são feitos à escola, que é a controladora dos dados pela LGPD.

## Você é gestor de uma escola que usa o Klass

Use o canal de atendimento combinado no contrato da sua escola.

## Você faz parte do time

- **Bug ou melhoria:** abra uma issue usando um dos formulários do repositório.
- **Dúvida de produto ou regra de negócio:** procure a spec e o Glossário no `docs-klass-hub`; se não estiver lá, pergunte ao Product Owner antes de codar.
- **Vulnerabilidade:** siga o [SECURITY.md](SECURITY.md), nunca uma issue.
